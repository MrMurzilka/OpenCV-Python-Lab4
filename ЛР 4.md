## 3. Теоретическая часть

### 3.1. OpenCV и NumPy

**OpenCV (Open Source Computer Vision Library)** — кроссплатформенная библиотека алгоритмов компьютерного зрения с открытым исходным кодом. В Python OpenCV тесно интегрирована с **NumPy**, обеспечивающей поддержку высокопроизводительных многомерных массивов.

#### 3.1.1. Представление изображений в памяти

Изображение в памяти представляет собой объект **ndarray** (N-dimensional array):

- **Полутоновое изображение:** двумерная матрица H×W (высота × ширина), каждый элемент — uint8 (0–255)
- **Цветное изображение:** трёхмерный массив H×W×C, где C — количество каналов

```python
import cv2
import numpy as np

# Загружаем изображение
img = cv2.imread('photo.jpg')

# Проверяем размеры
print(f"Высота: {img.shape[0]}")
print(f"Ширина: {img.shape[1]}")
print(f"Каналы: {img.shape[2]}")
print(f"Тип данных: {img.dtype}")
```

### 3.2. Цветовые пространства

**Важная особенность OpenCV:** цветные изображения загружаются и хранятся в цветовом пространстве **BGR** (Blue, Green, Red), а не RGB.

#### 3.2.1. Преобразование между цветовыми пространствами

```python
# BGR → Grayscale
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# BGR → HSV
hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

# BGR → RGB (для Matplotlib)
rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
```

#### 3.3.3. Работа с областями интереса (ROI)

**ROI (Region of Interest)** — выделение частей изображения через срезы NumPy:

```python
# Выделение центральной области 100×100
h, w = img.shape[:2]
y_start, x_start = h//2 - 50, w//2 - 50
roi = img[y_start:y_start+100, x_start:x_start+100]

# Инверсия цветов в ROI
img[y_start:y_start+100, x_start:x_start+100] = 255 - roi
```

### 3.4. Фильтрация изображений

**Пространственная фильтрация** — применение ядра свёртки (kernel) к скользящему окну изображения.

#### 3.4.1. Линейные фильтры

```python
# Усредняющий фильтр (box filter)
blurred = cv2.blur(img, (5, 5))

# Гауссовский фильтр
gaussian = cv2.GaussianBlur(img, (5, 5), 0)
```

#### 3.4.2. Нелинейные фильтры

```python
# Медианный фильтр (эффективен против шума «соль и перец»)
median = cv2.medianBlur(img, 5)

# Двусторонний фильтр (сохраняет края при сглаживании)
bilateral = cv2.bilateralFilter(img, 9, 75)
```

### 3.5. Работа с видео

#### 3.5.1. Захват видео с камеры

```python
# Инициализация захвата
cap = cv2.VideoCapture(0)  # 0 — основная камера

if not cap.isOpened():
    print("Не удалось открыть камеру")
else:
    # Чтение кадров в цикле
    while True:
        ret, frame = cap.read()
        if not ret:
            break
        
        # Обработка кадра
        gray_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        
        # Отображение
        cv2.imshow('Camera', gray_frame)
        
        # Выход по 'q'
        if cv2.waitKey(1) & 0xFF == ord('q'):
            break
    
    # Освобождение ресурсов
    cap.release()
    cv2.destroyAllWindows()
```

#### 3.5.2. Запись видеофайла

```python
# Инициализация записи
fourcc = cv2.VideoWriter_fourcc(*'XVID')  # или 'mp4v'
out = cv2.VideoWriter('output.avi', fourcc, 20.0, (640, 480))

# Запись кадров из исходного видео
cap = cv2.VideoCapture('input.avi')
while cap.isOpened():
    ret, frame = cap.read()
    if not ret:
        break
    out.write(frame)

cap.release()

# Завершение записи
out.release()
```

## 6. Обработка ошибок

При работе с OpenCV необходимо обрабатывать следующие ошибки:

1. **Файл не найден** — проверьте существование файла перед загрузкой
2. **Неверный формат** — убедитесь, что файл является изображением/видео
3. **Камера недоступна** — проверьте доступность устройства захвата
4. **Недостаточно памяти** — обработайте большие изображения

Пример обработки ошибок:

```python
import os

def safe_load_image(file_path):
    """Безопасная загрузка изображения."""
    if not os.path.exists(file_path):
        raise FileNotFoundError(f"Файл не найден: {file_path}")
    
    img = cv2.imread(file_path)
    if img is None:
        raise ValueError(f"Не удалось загрузить изображение: {file_path}")
    
    return img
```

### 3.5. Чтение EXIF-метаданных с помощью Pillow

Для чтения EXIF-метаданных изображений можно использовать библиотеку Pillow:

```python
from PIL import Image
from PIL.ExifTags import TAGS, IFD


def read_exif_data(image_path):
    """Читает EXIF-метаданные изображения."""
    try:
        img = Image.open(image_path)
        exif_data = img._getexif()
        
        if not exif_data:
            print("EXIF-данные не найдены")
            return {}
        
        # Преобразуем числовые коды в читаемые имена
        exif_dict = {}
        for tag, value in exif_data.items():
            tag_name = TAGS.get(tag, f"Unknown Tag {tag}")
            exif_dict[tag_name] = value
        
        return exif_dict
    except Exception as e:
        print(f"Ошибка при чтении EXIF: {e}")
        return {}


# Пример использования
exif_info = read_exif_data('image.jpg')
for tag, value in exif_info.items():
    print(f"{tag}: {value}")
```
